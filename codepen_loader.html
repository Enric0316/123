APP 使用教學與手機離線下載指南

\r\n

包含 100% 離線安裝、iCloud 備份與好友分享教學

\r\n
\r\n
\r\n\r\n \r\n
\r\n

\r\n 1. 如何下載到 iPhone 永遠離線使用？\r\n

\r\n
    \r\n
  1. 雙擊電腦資料夾內的 點我下載到手機離線.bat 啟動通道。
    2. \r\n
  2. iPhone 用 Safari 瀏覽器 開啟電腦顯示的 https:// 加密網址。
    3. \r\n
  3. 點擊 Safari 螢幕底部 「分享按鈕 📤」 ➔ 「加入主畫面」。
    4. \r\n
  4. 完成！手機桌面上會出現獨立 APP，此時即可關閉電腦。在日本飛航模式、無網路時點桌面 APP 100% 秒開離線使用！
    5. \r\n
\r\n
\r\n\r\n \r\n
\r\n

\r\n 2. 如何上傳備份至 iCloud 雲端硬碟？\r\n

\r\n
    \r\n
  1. 在 APP 中點擊 「紀念冊」 頁面內頂部的 「💾 匯出備份 (JSON)」 按鈕。
    2. \r\n
  2. iPhone 會彈出儲存選單，選擇儲存至 「檔案 (Files)」App ➔ 「iCloud 雲端硬碟」。
    3. \r\n
  3. 換新手機或重裝 APP 時，點擊 「📥 匯入紀錄」 選取該 JSON 檔即可瞬間復原所有照片與筆記！
    4. \r\n
\r\n
\r\n\r\n \r\n
\r\n

\r\n 3. 如何分享行程與照片給同行好友？\r\n

\r\n
    \r\n
  • 分享獨立網址：把電腦產生的 HTTPS 網址發到 Line，親友用 Safari 打開點「加入主畫面」也可取得一模一樣的 APP。
    • \r\n
  • 分享照片與日記：點擊 「📸 匯出相本 (HTML)」 傳給朋友，朋友打開就能直接瀏覽精美的相片故事書！
    • \r\n
