# 🌐 永久免費雲端部署教學 (GitHub Pages / Vercel)

本 App 為標準全端靜態 Progressive Web App (PWA)，支援**100% 免費永久託管**，部署後網址 **24 小時不斷線、無需開電腦、換電腦零影響、可直接分享 Line 給親友**！

---

### 🚀 方式一：GitHub Pages 部署 (最推薦、最穩定)

1. **建立 GitHub 儲存庫**：
   - 開啟 [GitHub](https://github.com)，點擊右上角 `+` -> `New repository`。
   - 命名為 `nagoya-travel`，設為 `Public`，點擊 `Create repository`。

2. **上傳本資料夾檔案**：
   - 將本資料夾 (`2027名古屋`) 內的所有檔案 (`index.html`, `app.js`, `style.css`, `sw.js`, `manifest.json` 等) 上傳或推送到該 Repository。

3. **開啟 GitHub Pages 啟用永久網址**：
   - 進入 Repository 的 `Settings` -> 左側選單 `Pages`。
   - 在 `Source` 選擇 `Deploy from a branch` -> 選擇 `main` / `root` -> 點擊 `Save`。
   - **完成！** 約 1 分鐘後您將獲得專屬永久網址：
     `https://<您的GitHub帳號>.github.io/nagoya-travel/`

---

### ⚡ 方式二：Vercel / Netlify 部署 (一鍵拖曳)

1. 開啟 [Vercel](https://vercel.com) 或 [Netlify](https://www.netlify.com)。
2. 登入後將 `2027名古屋` 資料夾直接拖曳 (Drag and drop) 到網頁視窗。
3. 幾秒鐘後即可獲得免費 HTTPS 網址（如 `https://nagoya-travel.vercel.app`）。

---

### 📱 給同行親友安裝觀看步驟

1. 把您的 GitHub Pages 或 Vercel 網址用 Line 發送給同行親友。
2. 親友用 iPhone 的 **Safari** 打開該網址。
3. 點擊 Safari 底部「分享按鈕」 -> **「加入主畫面」**。
4. 大家的桌面都會出現 **「名古屋9日遊」** App，離線與雲端即時同步均可使用！
